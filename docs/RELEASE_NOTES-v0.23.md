# 狮课表 v0.23 · 测试版 🦁

首个公开测试版本 —— 把教务系统导出的 **PDF 课表**一键导入成漂亮的周视图课表。

## 📲 下载安装

| 文件 | 说明 |
|------|------|
| `狮课表-v0.23-测试版.apk` | 适用于 **Android 7.0（API 24）及以上** |

安装方式：手机设置里允许「安装未知来源应用」后，点击 APK 安装即可。

> ⚠️ 本包为 **debug 签名**的测试版，仅用于体验和测试；如需上架应用商店请自行配置正式签名。

## ✨ 功能一览

- 📄 **正方教务 PDF 导入** —— 支持「班级课表」和「个人课表」两种导出格式，自动解析课程名、教师、教室、周次、单双周
- 📅 **周视图课表** —— 左侧节次 + 起止时间，右侧 7 天；**跨节课程自动合并**显示
- 👉 **滑动换周** —— 左右滑动切换周次，也可点 `◀` `▶` 平滑滚动
- 🎨 **状态着色** —— 「非本周」课程灰显并标注；**今天已上完**的课自动变灰
- ✏️ **自定义增删改** —— 顶部 `+` 手动添加课程；点击课程块可**编辑 / 删除**
- ⏰ **10 节作息时间表** —— 08:20 ~ 20:35
- 🏫 **校区教室** —— 课程块直接显示 `@校区 教学楼 教室`
- 💾 **纯本地存储** —— 不联网、不上传任何数据

## 🐛 已修复

- 删除一门课程会把**整个课表删光**（PDF 导入的课程 id 全为 0 导致的匹配错误）
- 相关兜底：老数据在启动时会自动修复 id，不会再误删；「清空全部课程」也加了二次确认

## ⚠️ 已知问题

- 目前仅适配**正方教务**导出的课表 PDF
- 节次固定 10 节，PDF 中第 11 节及以后的课程会被归到第 10 节
- 同一时间格有多门课时，暂只显示第一门

## 🧱 技术栈

Kotlin 2.2 · Jetpack Compose (Material 3) · PDFBox-Android 2.0.27 · JSON 本地存储
